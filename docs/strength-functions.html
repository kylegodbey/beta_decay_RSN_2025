About Strength Functions

This page displays Gamow-Teller (GT) and first-forbidden (FF) charge-exchange strength functions from linear response QRPA calculations on axially-deformed RHB ground states.

  • Framework: RHB + linear response QRPA with DD-PCX interaction
  • Modes: GT (Gamow-Teller) and FF (First-Forbidden 1⁻)
  • K-decomposition: K = 0, K = 1, and Total = K₀ + 2K₁
  • Available nuclei: 105 selected nuclei
