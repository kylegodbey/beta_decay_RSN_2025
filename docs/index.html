Welcome

This interactive web application provides access to β-decay datasets computed with axially deformed RHB + pnQRPA using the DD-PC1 and DD-PCX interactions.

Dataset Overview

Beta-Decay Tables

  • Interactions: DD-PC1 and DD-PCX
  • Number of nuclei: ~4,900 per interaction
  • Data includes: Neutron/proton numbers, binding energies, deformation parameters, Q-values, half-lives, and first-forbidden contributions

Strength Functions

  • Nuclei: 105 selected nuclei (DD-PCX interaction only)
  • Modes: Gamow-Teller (GT) and First-Forbidden (FF) spin-dipole
  • Decomposition: K = 0 and K = 1 components, plus total strength
  • Format: Energy (MeV) vs. Strength function S(E)
